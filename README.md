# Hi, I'm Mateo Cardenas 👋

**Electronic Engineering student at Universidad Nacional de Colombia**  
Interested in **embedded systems, firmware development, and electronic design**.

I use this GitHub profile to document my learning process, engineering prototypes, and collaborative software projects. I value reproducible builds, clear technical documentation, and being transparent about what has been implemented and tested.

## Technical focus

- **Embedded firmware:** C, STM32, peripheral configuration, register-level programming, and STM32 HAL.
- **Software development:** C++, CMake, Git, Linux, and TCP/IP socket programming.
- **Electronics & prototyping:** microcontroller interfaces, digital peripherals, and portable-device design.
- **Currently exploring:** ESP-IDF, ESP32-based systems, and hardware/software integration.
